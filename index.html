Formato GLB / glTF 2.0

Los modelos se exportan desde SketchUp en formato .glb, el estándar moderno para gráficos 3D en la web. Preserva materiales, texturas y jerarquía de objetos.

Renderizado con Three.js

El motor Three.js utiliza WebGL para renderizar en tiempo real con iluminación PBR (Physically-Based Rendering), sombras dinámicas y mapeo de entorno.

Soporte WebXR / VR

Gracias a la API WebXR integrada en Three.js, el visor es compatible con Meta Quest, HTC Vive y cualquier dispositivo de Realidad Virtual conectado al navegador.
